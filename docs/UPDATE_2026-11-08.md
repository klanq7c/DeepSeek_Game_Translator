## 本版更新

- **API 连通检测**：配置窗口新增“检测连通”，可在保存前验证当前地址、模型和 Key，并查看认证、权限、限流、超时等错误提示。
- **本地模型适配**：延长 Ollama、LM Studio 等本机服务的首次响应等待，显示模型加载提示；标准本机 Ollama 接口请求关闭思考模式，本地翻译默认采用较小批次，也可调整批次预算。
- **API 配置体验**：模型列表显示提供商返回的名称与 API ID，刷新保留当前选择；切换提供商时分别保留各家的 Key 草稿。配置和提示窗口统一为星夜主题。
- **半汉化补译**：继续翻译中英混合文本中的剩余英文，保护原有中文、变量和格式标记。
- **Ren'Py**：改进中文字体补字，保留游戏原有字体、图标和字体组规则；修复嵌套插值、长目录预热漏句，并减少无关文本的重复刷新。
- **RPG Maker**：MV/MZ 新增部分菜单及 UI 图片文字的自动识别与翻译；改进插件文本、中文换行及颜色控制符处理，修复命令字段次序不同造成的预热漏句。
- **Unity**：改进 Mono 与 IL2CPP 的富文本、中文字体及动态界面适配，修复字体覆盖层的颜色跟随和缓存读取失败后的覆盖问题，并优化可选深预取的扫描预算。
- **Godot**：完善富文本标签保护、导出资源采集和启动预检，减少格式损坏及错误回退。
- **启动与缓存稳定性**：启动、还原、清缓存和服务启停在后台执行，避免同时操作互相干扰；改进长路径文件操作，严格检查提供商响应与缓存记录，避免异常内容进入译文缓存。

## 升级方法

1. 完全退出游戏和旧版翻译器。
2. 将下载的 EXE 改名为 `ds游戏翻译器.exe`，替换原目录中的同名程序；也可解压 ZIP，用其中的同名程序替换。
3. 重新打开翻译器，选择游戏目录并开始翻译，使游戏加载更新后的组件。

已有 API 配置和翻译缓存可继续使用。启动器会自动更新自有组件，不自动覆盖真实配置、翻译记忆或第三方运行时。

## 使用提示

- **检测连通**会发送一次真实的短聊天请求，云端服务可能产生少量费用。检测不自动保存配置；保存后重启翻译服务生效。本机模型首次加载可能较慢，回环地址使用 120 秒响应等待，超过等待仍会报告超时。
- **本地模型**须先启动 Ollama、LM Studio 等服务，并填写已安装模型的准确 ID。标准本机 Ollama 接口请求关闭思考模式；其他地址和服务不自动附加该选项。批次调整见[本地模型使用说明](https://github.com/klanq7c/DeepSeek_Game_Translator/blob/v0.4.1.1/docs/USER_GUIDE.md#接入本地模型ollama--lm-studio)。
- **图片文字识别**目前面向 Windows NW.js 的 RPG Maker MV/MZ，需要系统英文 OCR 语言包。只处理支持的图片加载路径及可可靠替换的文字区域；复杂背景、艺术字体或无法容纳译文的区域可能保留原图。
- **Unity 游戏**另需按[使用说明](https://github.com/klanq7c/DeepSeek_Game_Translator/blob/v0.4.1.1/docs/USER_GUIDE.md)安装对应的 BepInEx/XUnity 等运行组件；程序不附带第三方运行时或游戏文件。
