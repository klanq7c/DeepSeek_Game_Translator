## 本版更新

- **启动器**：重新设计星夜主题首页、操作卡片、按钮和日志区域；减少装饰刷新，改进文件拖放与服务关闭提示。
- **Godot**：修复菜单动画造成的原文回闪、选项被富文本拆开及部分未命中影响整块补译的问题；改进动态控件、场景切换、暂停菜单、导出包识别与启动预检。
- **Ren'Py**：改进旧版本界面刷新，避免迟到响应覆盖已有译文。
- **RPG Maker**：完善菜单和已完成对话的延迟补译、断线恢复及窗口复用，保留颜色、字号和变量控制符。
- **Unity**：改进动态菜单扫描、富文本标签保护与 IL2CPP 响应检查，完善中文字体回退及部分精简程序集兼容。
- **API 配置**：从当前端点和账号刷新模型目录，支持手动输入并保留已选模型；改进分页、权限与目录缺项提示，修复部分 Unicode 模型名保存问题。
- **缓存与稳定性**：改进 API 超时处理、缓存写入失败恢复及不完整末行追加，减少重复解析与界面绘制开销。

## 升级方法

1. 完全退出游戏和旧版翻译器。
2. 将下载的 EXE 改名为 `ds游戏翻译器.exe`，替换原目录中的同名程序；也可解压 ZIP，用其中的同名程序替换。
3. 重新打开翻译器，选择游戏目录并开始翻译，使游戏加载更新后的组件。

已有 API 配置和翻译缓存可继续使用。启动器会自动更新自有组件，不自动覆盖真实配置、翻译记忆或第三方运行时。

## 使用提示

Unity 游戏需先在程序所在目录安装对应运行组件：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/install_runtime_payloads.ps1 -All
```

程序不附带第三方运行时或游戏文件。完整使用方法见程序包内的 `README_使用说明.txt`。
