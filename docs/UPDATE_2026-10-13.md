# 0.4.1.0 更新说明（2026-10-13）

本次发布 `0.4.1.0`，汇总 `0.4.0.0` 之后的兼容性修复、启动页改版及性能优化，包含重新构建的 Windows 程序。

## 下载与升级

- `ds-translator_0.4.1.0.exe`：单文件启动器。
- `ds-translator_0.4.1.0.zip`：程序、更新日志、使用说明和许可文件。
- `DeepSeek_Game_Translator_source_0.4.1.0.zip`：经过发布检查的源码包。

退出旧翻译器，把新版程序放到原来的安装目录；单文件下载可改名为 `ds游戏翻译器.exe` 后替换旧程序。重启翻译器并重新启动游戏，让脚本及插件更新生效。API 配置与翻译记忆保留。Unity 第三方运行时仍由 `scripts/install_runtime_payloads.ps1 -All` 从上游安装。

本版统一下载文件名，避免 GitHub 重写中文附件名；程序包补齐详细更新日志、字体许可和指纹清单。

## 启动器

- 重新设计星夜主题首页、操作卡片、按钮和日志区域；保留原有 16 个控件与游戏启动、还原、缓存管理流程。
- 动画按实际经过时间推进，仅刷新装饰区域；后台、最小化或系统减少动画设置生效时停止装饰刷新。
- C 与 C# 启动器同步复用绘图缓冲，尺寸、DPI、显示设备变化和窗口销毁时释放资源，异常保留诊断。
- C# 日志历史仅保留最近 2000 条，诊断输出仍逐条完整送达。
- 完善文件拖放、外部服务关闭确认及 Godot 预检进程退出处理，避免未完成操作被误报为成功。

## Godot

- 在绘制生命周期恢复已有缓存译文，处理选择动画和多层延迟赋值造成的原文回闪。
- 按逻辑选项组合被 BBCode、内联样式或左右链接拆开的文字；保留链接标识、颜色、箭头及控制信息。
- 设置页面允许已命中项目先显示译文，未命中项目继续后台排队；分辨率等数字和实际资源路径保持原样。
- 改进场景重进、动态控件、暂停菜单、HTTP 异常响应和超时后的请求槽释放。
- 扩展 PCK v4 及部分加密目录兼容处理，更新游戏或翻译脚本后重新校验受管理的补丁与预检结果。
- 单次控件或菜单处理共用文本计划，减少重复解析；绘制时的缓存恢复不发起网络请求。

## Ren'Py、RPG Maker 与 Unity

- Ren'Py：旧版本通过引擎主线程回调刷新界面，防止迟到的未完成响应覆盖已经命中的译文。
- RPG Maker：完善菜单和已完成对话的延迟补译、断线恢复、窗口复用及插件参数预热；动画改写文字时保留颜色、字号和变量控制符。
- Unity Mono / BepInEx 5、6：在动画 setter 中优先恢复已有译文，同一轮无写入扫描复用控件列表；动态启用、译文写入及回调异常时立即使列表失效，避免新控件漏扫。
- Unity IL2CPP / XUnity：严格验证响应 JSON 和译文内容，未完成、原文回显、空白或无效响应不作为成功译文。
- Unity 显示兼容：保护链接、精灵等富文本属性，兼容部分精简程序集的字体元数据访问；显示层标点处理不修改共享翻译记忆。
- 引入经过许可核验的 Noto CJK 字体回退资源，并保留完整 OFL 许可与文件指纹。

## API、缓存与构建

- 提供商预设仅指定地址；模型目录从当前端点及账号读取，支持手动输入，刷新保留用户选择，不自动替换已保存模型。
- 完善分页失败、无权限和目录缺项的提示，以及中文、emoji 模型名的配置保存。
- 改进提供方响应体大小限制与实际超时中断，释放失败请求占用的通道。
- 批量缓存写入在写入与刷新均成功后才确认持久化；失败记录可重试，追加时修复不完整的末行分隔。
- 减少缓存导出和 HTTP 响应构造的重复分配，增加构建指纹原子发布与故障恢复检查。
- 统一核心运行模块的中文说明注释，保留协议字段、技术标识和第三方许可原文。
