# 本地模型接入说明（2026-10-23）

本文保留本地模型适配的配置说明；这些变化已包含在 [0.4.1.1 更新](UPDATE_2026-11-08.md)中。

- 本机标准 Ollama 接口会明确关闭思考模式，让支持该选项的模型直接生成译文。
- 本地翻译默认每批最多 8 条、2048 个输入 UTF-8 字节，远程接口保留原有的 48 条、9600 字节默认值。
- API 配置增加 `batch_max_items` 和 `batch_char_budget`，可按本地模型能力调整批次；单条超出预算时单独发送，不截断原文。
- 已安装的 Index-Translate 等模型可在“配置 API”中选择 Ollama 后刷新选择，或手动填写准确的模型 ID，Key 留空。建议设置 `concurrency=1`。

为了减少游戏期间的显存占用，可先完成可扫描文本的预热，完全退出 Ollama 后保留翻译器本地服务。已有缓存继续可用，未缓存文本需要再次启动模型后补译。

详细步骤见[本地模型接入说明](USER_GUIDE.md#接入本地模型ollama--lm-studio)。
