## 修复范围

| 范围 | 原因与修改 | 回归入口 |
| --- | --- | --- |
| Unity Mono / BepInEx 5、6 | 读取失败曾被标成已完成，允许覆盖未导入的缓存。现在区分尝试结束与成功检查，隔离失败也阻止覆盖；持久化前可重新读取、合并并保留较新的实时译文 | `tests/unity_runtime_contract`：真实读取、隔离、调度与落盘方法，文件锁及损坏 JSON 注入 |
| C/C# 启动器 | 自身排除列表遗漏正式发行文件名。两版识别版本化发行名，并按实际程序路径排除改名后的自身 | `test_exe_selection.py`：实际两版检测入口与相邻 Unity 主程序评分 |
| C# 服务请求构造 | 无效 URI 在异常边界外抛出，后台线程使服务退出。现在构造请求前验证 URI，返回未解决结果并保留诊断 | `test_api_boundaries.py`：后台预热和实时请求、服务存活、失败不写缓存 |
| C# 慢速本地模型 | HttpClient 隐式 100 秒限制覆盖了 120—300 秒配置。现在由请求取消令牌统一控制截止时间 | 同上 `--slow`：真实 104 秒响应；现有停滞响应体超时测试 |
| C# 实时并发 | 只启动一个同步等待的实时线程。现在按配置建立实时工作池，空闲通道可以接收后续批次 | 同上：先确认首个请求到达提供商，再发第二个请求，以重叠事件断言并发 |
| RPG Maker | 控制符集合遗漏队伍成员和货币单位。现在拒绝缺失或改变 `\P[n]`、`\G` 的译文 | 生产 hook 菜单刷新，兼顾 `\V[n]`、颜色和保留令牌的正常译文 |
| Ren’Py | 收集时跳过转义括号，恢复时未跳过；跳过无效括号还会丢前缀。现在区分扫描位置与输出位置，保留字面片段 | `test_renpy_tokens.py`，普通插值、转义方括号/花括号及恶意新增令牌 |
| Godot C/C# 资源补丁 | 只校验括号平衡，没有比较标签。现在保留 BBCode 标签顺序、参数和自定义成对效果，拒绝损坏译文并汇总诊断 | `test_godot_text_format.py`：11 组两版验证及实际 C# 场景覆盖 |
| Unity IL2CPP / TMP 备用显示层 | 缓存首次颜色并把源颜色改成透明，无法辨认后续淡出。现在保留游戏颜色，每次更新读取最新值，只接管源组件 enabled 状态 | 源链接覆盖层方法：高亮、淡出到零、撤销、失活及隐藏失败 |
| 托管载荷构建 | 把输出目录作为依赖来源，非增量清理删除了唯一引用。现在先在构建目录创建独立引用快照，再构建两个 Mono 版本 | `test_unity_reference_staging.ps1`，以及不设置 `UNITY_MANAGED_DIR` 的完整重建 |
