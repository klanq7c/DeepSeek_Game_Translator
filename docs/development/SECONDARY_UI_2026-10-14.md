# 二级窗口主题统一（2026-10-14）

## 影响范围

启动器的 API 配置窗口，以及清除缓存、还原游戏、配置校验等确认/提示窗口。
C 与 C# 同步实现；翻译服务、引擎钩子、部署、预热和配置文件格式不变。

## 实现约定

- 深蓝标题区、月亮装饰、暖白卡片、暖金主按钮，与首页使用同一调色板。
- `dialog_theme.c` / `DialogTheme.cs` 持有二级窗口自己的字体、画刷、缩放和模态行为。
  使用相同的 MulDiv 取整；C# 的窗口局部缩放通过 `Theme.Sc(value, dpi)`。
- 原生编辑框与组合框保留输入法、密码遮罩、辅助功能和手动模型输入。
  按钮与模型列表选中项使用主题色，焦点/悬停状态可见。
- 窗口按所属显示器工作区居中；空间不足时收缩整个布局。DPI 变化重排控件，
  保留已有输入，不修改首页全局 DPI 或刷新模型目录。
- 表单按提供商、地址、模型、刷新、Key、取消、保存顺序切换焦点。
  Enter 执行当前按钮或保存；下拉展开时先交给系统处理选项；Esc 取消。
- 清缓存和还原的确认框保留原来的默认拒绝；Enter 默认取消，关闭和 Esc 也取消。
  提示框创建失败记录日志、返回失败，不能继续执行破坏性操作。
- 每个模态窗口只恢复自己禁用的父窗口，并在关闭后释放所拥有的绘图资源。
  模型网络请求仍走原来的异步生命周期；关闭窗口不能访问已释放的窗口资源。

## 验证入口与边界

- `build_native.bat`：完整构建及原有回归门禁。
- `api-config/theme-96/120/144/192`：API 表单、确认框的 C/C# 客户区位图完全一致；
  另行断言控件边界、字体、Tab 顺序、密码样式、DPI 切换保留输入以及取消行为。
- 确认框探针覆盖默认 Enter、Esc、明确确认、关闭和普通提示五条返回路径。
  不调用清缓存或还原功能，不改游戏文件。
- 原有模型目录守卫继续覆盖手动模型、保存的选择、目录缺项、厂商切换、失效响应
  和失败后保留输入。隐藏探针不联网、不保存配置。
- 实际桌面窗口使用独立测试目录检查。隐藏位图不能代替原生输入控件、弹出列表、
  DWM 标题栏及用户 DPI 下的实机观察，也不能证明所有显示器组合都已人工测试。

原始构建日志和截图留在 `.scratch/secondary-ui/`，不进入玩家更新日志或程序包。
