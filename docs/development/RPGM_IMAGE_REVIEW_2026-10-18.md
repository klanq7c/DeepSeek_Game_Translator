# RPG Maker 图片翻译复查（2026-10-18）

范围：RPG Maker 图片渲染模块及其回归。保持自动发现方案，不加入游戏专用词表、坐标或译图，不改共享服务器、翻译记忆和其他引擎。

## 复现与修复

### 已显示译文被后来的超长译文擦除

旧实现先改写 `state.applied`，再检查译文是否放得下。新值过长时虽然跳过绘字，最终仍提交从原图重建的画布，把已经显示的中文擦回英文。暂存画布绘制异常也会提前留下没有真正显示的 `applied` 值。

修复：先验证整图的显示计划；新译文放不下时继续使用上次已显示的值。画布与纹理提交后才更新显示记录。没有译文变化时不额外创建测量或暂存画布。

回归先确认失败，再验证正常译文→超长译文→未命中的完整链；另一文字区域同时更新时，已显示区域也必须保留。绘制异常不记未提交结果，MZ 的纹理通知仍只在真实修改时调用。

### OCR 协议的合法 JSON 错误形状可能使游戏异常

`null` 能通过 JSON 解析，但旧代码随后直接读取 `ready`；对象类型的请求号还会在数值转换时抛异常。这些异常发生在工作进程输出回调中，可能逃出渲染适配层。

修复：先核对对象、请求号类型和归属，再检查有界错误字符串或结果对象。协议失败使用已有工作进程故障边界关闭本会话识别、记录原因、保留原图，不返回成功翻译。

### 密集 OCR 结果的比较上限

双背景候选原先可能形成过长的两两比较。现在每个背景最多接受 512 个候选；超过上限整张图片保持原图，并通过 `image-text-plan` 报告 `OCR candidate budget exceeded`。不是把超额结果当成识别成功。
