# Ollama 本地翻译适配验证（0.4.1.1）

## 改动范围

范围为共享服务器的提供商请求、配置加载和批次调度。C 与 C# 服务同步适配，保留游戏引擎钩子、缓存契约和远程提供商行为。

- 标准本机 Ollama 端点明确发送 `reasoning_effort: "none"`。主机、端口和路径均严格匹配；其他本地服务、远程端点及已有 DeepSeek 选项保持隔离。
- 新增 `batch_max_items` 与 `batch_char_budget`，回环默认 8/2048，远程默认 48/9600；预算以待译文本的 UTF-8 字节数计，不包含系统提示词和上下文。
- 预热、实时合批和同步批量使用同一设置；超过预算的单条文本单独发送，不截断或丢弃。
- 本地运行配置使用单并发及 180 秒请求超时。此为本机配置，不作为源码中的模型预设，也不包含账号凭据。

## 自动回归

- `build_native.bat`：完整构建及内置门禁通过，生成版本为 0.4.1.1 的本机启动器，并嵌入两版服务。
- `tests/server_contract/run_model_defaults_tests.ps1`：102 项配置/请求检查、7 项 Unicode 模型配置检查通过，覆盖端点边界、三个请求模式、默认值及范围钳制。
- `tests/server_contract/test_local_batch_limits.py`：34 个实际服务与模拟提供商场景通过，覆盖三个调度入口、UTF-8 字节预算、显式覆盖、超预算单条及旧批次预算。
- `tests/server_contract/run_contract_tests.ps1`：两版服务合计 152 项检查通过，覆盖缓存、队列、失败恢复和持久化。
- 本次适配另经只读复核，未发现需要修改的边界问题。

## 真实模型联调

使用本地 Ollama 0.40.9 与 `index-translate:2b`（Q8_0），通过两版翻译服务分别执行单条、八条批量和两条带上下文预热。测试仅使用合成短文本与独立缓存。

两版均产生有效中文译文；`{player}`、`{slot}`、`%d`、`[E]`、`<b>...</b>` 和原有换行保持完整。关闭 Ollama 后重新启动测试服务，十一条已有缓存均从磁盘恢复并返回 `cache`，无需模型在线。

原有共享翻译记忆在验证前后的长度与 SHA-256 相同。旧 API 配置及构建产物保留在忽略的本地任务目录中，原始检查日志位于 `.scratch/ollama-index-integration/`，不纳入源码发布。

## 验证边界与最终状态

未启动或修改真实游戏，未完成具体游戏的字形、排版、长剧情和帧率验证。合成用例通过不代表所有游戏文本均能正确翻译。预热只能覆盖扫描器可见文本；未缓存的动态文本仍需要模型在线。

完成后 Ollama 桌面、后台服务与推理进程均已停止，Windows 登录自启保持禁用。本地开发版尚未公开发布，现有公开下载仍对应已发布版本。
