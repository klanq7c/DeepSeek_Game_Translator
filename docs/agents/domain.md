# Domain Docs

This is a single-context repository.

Before exploring or changing the code, engineering skills must read:

- `CONTEXT.md` for the shared domain vocabulary.
- Relevant decisions under `docs/adr/`, when that directory exists.
- `docs/MAINTENANCE_MAP.md` for subsystem ownership, guards, and verification.

Use the terms defined in `CONTEXT.md` in issue titles, hypotheses, tests, and
implementation notes. If a proposed change contradicts an ADR, surface that
conflict explicitly instead of silently overriding the decision.
