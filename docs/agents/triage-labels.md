# Triage Labels

| Canonical role | Local status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | More information is required from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation. |
| `wontfix` | `wontfix` | The issue will not be actioned. |

Skills must use the local status string that corresponds to the canonical role.
